# Delta Exciter Auto Script for 'Eat the World'

This script provides auto sell, auto grab, and auto eat features for Delta Exciter in the game 'Eat the World'. It is designed to enhance the gameplay experience by automating repetitive tasks, allowing players to focus on other aspects of the game.

## Installation

1. Open Roblox Studio and load your 'Eat the World' game.
2. Create a new Script in ServerScriptService.
3. Copy and paste the content of DeltaExciterAutoScript.server.lua into the Script.

## Use

1. Adjust the configuration values in the script to suit your preferences:
   - `MAX_SIZE`: The size at which Delta Exciter will auto sell.
   - `SELL_DISTANCE`: The distance to the sell point.
   - `GRAB_DISTANCE`: The distance to grab food.
   - `EAT_DISTANCE`: The distance to eat food.
2. Run the game in Roblox Studio or publish it to Roblox.
3. The script will automatically handle auto sell, auto grab, and auto eat features for Delta Exciter.
